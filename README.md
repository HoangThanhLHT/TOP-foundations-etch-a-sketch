# Etch-a-Sketch

## Introduction

A browser version of something between a sketchpad and an Etch-A-Sketch.

- A button on the top of the screen that will send the user a popup asking for the number of squares per side for the new grid.
- A grid of squares. It have “hover” effect so that the grid divs change random color when your mouse passes over them.
- A progressive darkening effect where each interaction darkens the square by 10%. The goal is to achieve completely colored square in only ten interactions.
